Introducción

Figma es una plataforma de diseño colaborativo basada en la nube que ha revolucionado la forma en que los equipos crean interfaces digitales. Permite diseñar interfaces de usuario, crear prototipos interactivos de alta fidelidad y desarrollar sistemas de diseño escalables, todo en tiempo real con múltiples colaboradores. Su naturaleza multiplataforma y su potente conjunto de herramientas la convierten en la elección preferida de diseñadores UX/UI, desarrolladores y product managers en todo el mundo.

Herramientas de Selección y Manipulación

1. Move Tool (V)

Qué hace: Permite seleccionar y mover objetos, capas o grupos dentro del lienzo. También funciona para hacer clic profundo (deep select) manteniendo Cmd/Ctrl mientras haces clic para seleccionar elementos anidados.

Cuándo usarlo: Es tu herramienta principal para organizar y posicionar elementos. Úsala para ajustar el layout, crear composiciones visuales y reorganizar componentes en tu diseño.

Consejo profesional: Mantén presionada la tecla espaciadora temporalmente para activar Hand Tool sin cambiar de herramienta.

2. Scale Tool (K)

Qué hace: Escala objetos de forma proporcional o libre, permitiendo transformar tamaños sin necesidad de ajustar manualmente cada dimensión. Mantén Shift para escalar proporcionalmente.

Cuándo usarlo: Ideal para redimensionar íconos, imágenes, ilustraciones o grupos completos de elementos manteniendo la armonía visual. Especialmente útil cuando trabajas con assets de diferentes tamaños.

Consejo profesional: Usa Alt/Option mientras escalas para hacerlo desde el centro del objeto.

3. Hand Tool (H)

Qué hace: Permite desplazarse por el lienzo sin modificar, seleccionar o mover objetos. Es esencial para la navegación fluida en proyectos extensos.

Cuándo usarlo: Perfecto para navegar en proyectos con múltiples artboards, sistemas de diseño complejos o cuando estás revisando flujos completos de usuario.

Consejo profesional: Usa la rueda del mouse o trackpad para hacer zoom mientras te desplazas.

4. Frame Tool (F)

Qué hace: Crea contenedores (frames) que funcionan como artboards o pantallas independientes. Los frames son fundamentales en Figma y se comportan de forma diferente a los grupos.

Cuándo usarlo: Para crear pantallas de aplicaciones móviles, páginas web, componentes contenedores o secciones de tu diseño. Los frames permiten aplicar Auto Layout y son esenciales para el diseño responsivo.

Herramientas de Dibujo

1. Formas Básicas (R, O, L)

Qué hace: Crea formas geométricas fundamentales: rectángulos (R), elipses/círculos (O), líneas (L), polígonos y estrellas. Mantén Shift para crear formas perfectamente proporcionadas.

Cuándo usarlo: Para construir la base de cualquier interfaz: botones, tarjetas, contenedores, avatares, separadores, badges, íconos geométricos y elementos decorativos. Son los bloques fundamentales de construcción en diseño UI.

Consejo profesional: Doble clic en cualquier forma para ajustar propiedades específicas como el radio de esquinas o el número de lados en polígonos.

Formas basicas

2. Pen Tool / Vector Tool (P)

Qué hace: Crea trazos vectoriales personalizados mediante puntos de ancla (anchor points) y curvas de Bézier. Permite crear formas orgánicas y precisas con control total sobre cada segmento.

Cuándo usarlo: Para diseñar íconos personalizados, ilustraciones vectoriales, logotipos, formas complejas, ondas decorativas o cualquier elemento que requiera curvas y trazos precisos.

Consejo profesional: Usa Pencil Tool (Shift + P) para dibujar a mano alzada y que Figma suavice automáticamente tus trazos.

3. Text Tool (T)

Qué hace: Crea y edita capas de texto con control completo sobre tipografía, espaciado, alineación y estilos. Soporta Google Fonts y fuentes locales.

Cuándo usarlo: Para cualquier contenido textual: títulos, subtítulos, párrafos, etiquetas de botones, placeholders, microcopy y toda la jerarquía tipográfica de tu interfaz.

Consejo profesional: Define estilos de texto reutilizables para mantener consistencia tipográfica en todo tu proyecto.

lapiz de vector y Lapiz normal

4. Boolean Operations

Qué hace: Combina formas usando operaciones de unión, sustracción, intersección y exclusión para crear formas complejas a partir de figuras simples.

Cuándo usarlo: Para crear íconos personalizados, formas irregulares, recortes en imágenes o cualquier diseño que requiera combinación de geometrías.

Comandos de Alineación y Distribución

1. Alineación de Objetos

Qué hace: Alinea elementos seleccionados respecto a los bordes (izquierda, derecha, arriba, abajo) o al centro (horizontal, vertical). Puedes alinear respecto al frame contenedor o a la selección.

Cuándo usarlo: Fundamental para mantener orden visual en listas, grids, formularios, menús de navegación y cualquier conjunto de elementos que requiera alineación consistente.

Consejo profesional: Usa Ctrl/Cmd + clic en los íconos de alineación para cambiar entre alinear a la selección o al frame contenedor.

Alineamiento

2. Distribución de Objetos

Qué hace: Distribuye elementos equitativamente en el eje horizontal o vertical, manteniendo espaciado uniforme entre ellos.

Cuándo usarlo: Esencial para crear ritmo visual consistente en galerías de imágenes, botones de acción, cards, menús, iconografía y cualquier conjunto de elementos repetitivos.

Consejo profesional: Combina con Auto Layout para distribución automática y responsiva.

Distribucion de objetos

3. Tidy Up (Ctrl + Alt + Shift + T)

Qué hace: Organiza automáticamente elementos seleccionados en una cuadrícula ordenada basándose en su posición actual.

Cuándo usarlo: Perfecto para organizar rápidamente conjuntos de componentes, íconos, screens o elementos que estén desordenados en el canvas.

4. Smart Selection

Qué hace: Al seleccionar múltiples objetos con espaciado consistente, Figma detecta automáticamente el patrón y te permite ajustar el espaciado entre todos simultáneamente.

Cuándo usarlo: Para ajustar rápidamente el espaciado en listas, botones o cualquier conjunto de elementos con ritmo visual.

Trabajo con Componentes y Sistemas de Diseño

1. Crear Componentes (Ctrl/Cmd + Alt + K)

Qué hace: Convierte cualquier elemento o grupo en un componente maestro reutilizable. Cualquier cambio en el maestro se refleja automáticamente en todas sus instancias.

Cuándo usarlo: Para crear elementos reutilizables como botones, campos de formulario, cards, navegación, modales, o cualquier patrón que se repita. Es la base de un sistema de diseño eficiente.

Consejo profesional: Organiza tus componentes maestros en una página separada para mantener tu biblioteca ordenada.

2. Variantes de Componentes

Qué hace: Agrupa múltiples versiones de un componente (estados, tamaños, tipos) en un solo componente con propiedades intercambiables. Reduce significativamente el desorden en tu biblioteca.

Cuándo usarlo: Para gestionar diferentes estados de un botón (default, hover, pressed, disabled), tamaños (small, medium, large), tipos (primary, secondary) o cualquier variación sistemática de un componente.

Consejo profesional: Usa propiedades booleanas (true/false) para características on/off como "tiene ícono" o "está cargando".

3. Crear Estilos (Text Styles, Color Styles, Effect Styles)

Qué hace: Define estilos reutilizables para tipografía, colores y efectos (sombras, desenfoque) que pueden aplicarse globalmente y actualizarse desde un punto central.

Cuándo usarlo: Fundamental al diseñar un sistema de diseño o design system. Mantiene consistencia visual en todo el proyecto y facilita cambios globales de marca o tema.

Consejo profesional: Nombra tus estilos de forma jerárquica (ej: "Text/Heading/H1", "Colors/Primary/500") para mejor organización.

4. Auto Layout (Shift + A)

Qué hace: Convierte frames en contenedores flexibles que ajustan automáticamente su tamaño según su contenido, similar a Flexbox en CSS. Permite diseñar componentes verdaderamente responsivos.

Cuándo usarlo: Para crear botones que se ajusten al texto, listas dinámicas, cards flexibles, menús responsivos o cualquier componente que deba adaptarse a diferentes contenidos.

Consejo profesional: Combina múltiples niveles de Auto Layout para crear layouts complejos y responsivos.

5. Constraints

Qué hace: Define cómo se comportan los elementos cuando su contenedor cambia de tamaño (fijo, escalar, centro, arriba, abajo, izquierda, derecha).

Cuándo usarlo: Para diseño responsivo, asegurando que elementos como logotipos permanezcan fijos mientras otros se adaptan al cambio de tamaño del frame.

Herramientas de Colaboración

1. Comentarios (C)

Qué hace: Permite añadir comentarios directamente sobre el diseño para feedback, discusiones o anotaciones. Los comentarios pueden ser resueltos y tienen hilos de conversación.

Cuándo usarlo: Durante revisiones de diseño, feedback de stakeholders, QA visual o comunicación asíncrona con el equipo.

2. Multiplayer y Cursores en Tiempo Real

Qué hace: Muestra los cursores y acciones de otros colaboradores en tiempo real, permitiendo trabajo simultáneo sin conflictos.

Cuándo usarlo: Para sesiones de design critique, pair designing, workshops colaborativos o simplemente trabajar en equipo de forma síncrona.

3. Dev Mode

Qué hace: Proporciona a los desarrolladores acceso a especificaciones de diseño, código CSS, medidas exactas y assets exportables directamente desde Figma.

Cuándo usarlo: Durante el handoff entre diseño y desarrollo, para asegurar implementación precisa y facilitar la comunicación con ingenieros.

Plugins y Extensibilidad

Ecosistema de Plugins

Qué hace: Figma tiene miles de plugins que extienden su funcionalidad: generación de contenido, accesibilidad, iconos, imágenes, exportación avanzada, integración con otras herramientas y mucho más.

Plugins populares: Iconify (íconos), Unsplash (imágenes), Content Reel (contenido), Stark (accesibilidad), Autoflow (user flows), Remove BG (eliminar fondos).

Cuándo usarlos: Para acelerar workflows repetitivos, añadir funcionalidades específicas o integrar servicios externos en tu proceso de diseño.
