¿Qué es una Expresión?

Una expresión es cualquier combinación válida de valores, variables y operadores que produce un resultado. Las expresiones se utilizan para realizar cálculos, comparaciones y evaluaciones dentro de un programa o ejercicio matemático. Dependiendo del tipo de datos y operaciones, pueden producir resultados numéricos, booleanos o de texto.

  • Expresiones aritméticas: realizan operaciones matemáticas como suma o multiplicación.
    • Ejemplo:
8 + 5 * 2
Resultado: 18
(Primero se multiplica 5 × 2 = 10, luego 8 + 10 = 18)

    Las expresiones aritméticas son combinaciones de números, variables y operadores matemáticos como suma, resta, multiplicación o división. Su propósito es realizar cálculos que generen un resultado numérico. Estas expresiones siguen reglas de prioridad, por lo que primero se resuelven multiplicaciones y divisiones, antes que sumas y restas.

  • Expresiones lógicas: evalúan condiciones que dan como resultado verdadero o falso.
    • Ejemplo:
(10 > 3) && (5 < 2)
Resultado: false
(La segunda condición es falsa, por lo tanto el AND completo es false)

    as expresiones lógicas se encargan de evaluar condiciones usando operadores como AND (&&), OR (||) y NOT (!). Estas permiten combinar varias comparaciones y determinar si un conjunto de condiciones se cumple o no. El resultado también es un valor booleano. Son muy útiles en estructuras de control y validaciones.

  • Expresiones relacionales: comparan valores para verificar relaciones como mayor o menor.
    • Ejemplo:
7 >= 4
Resultado: true
(Porque 7 es mayor o igual a 4)

    Estas expresiones son fundamentales en la toma de decisiones, ya que permiten saber si se cumple una condición dentro de un programa o ejercicio.

Tipos de Operadores

1. Operadores Aritméticos

Los operadores aritméticos se utilizan para realizar operaciones matemáticas básicas como suma, resta, multiplicación y división. Son esenciales para crear expresiones que produzcan resultados numéricos.

Ejemplo:
8 + 5 * 2
Resultado: 18
(Primero se multiplica 5 × 2 = 10, luego 8 + 10 = 18)

Estos operadores siguen reglas de prioridad, donde las multiplicaciones y divisiones se ejecutan antes que las sumas y restas. Son útiles para cualquier cálculo que involucre valores numéricos.

2. Operadores Relacionales

Los operadores relacionales permiten comparar dos valores para determinar si existe una relación entre ellos, como igualdad o diferencia. Su resultado siempre es booleano: verdadero (true) o falso (false).

Ejemplo:
7 >= 4
Resultado: true
(Porque 7 es mayor o igual a 4)

Este tipo de expresiones es fundamental en estructuras condicionales como if, while o validaciones, ya que permiten determinar si una condición se cumple.

3. Operadores Lógicos

Los operadores lógicos permiten evaluar o combinar condiciones booleanas. Se emplean para crear expresiones más complejas que determinan si múltiples afirmaciones son verdaderas o falsas.

Ejemplo:
(10 > 3) && (5 < 2)
Resultado: false
(La segunda condición es falsa, por lo tanto el AND completo es false)

Estos operadores son esenciales para controles de flujo que requieren validar más de una condición al mismo tiempo, como decisiones compuestas o verificaciones avanzadas de datos.

5 Ejercicios sobre Funciones

Ejercicio 1: Suma de dos números

fun sumar(a: Int, b: Int): Int {
    return a + b
}

La función recibe dos números y retorna su suma. Si llamamos sumar(4, 6), el resultado será 10.

Ejercicio 2: Comprobar si un número es par

fun esPar(n: Int): Boolean {
    return n % 2 == 0
}

La expresión n % 2 == 0 determina si el número es divisible entre 2. Por ejemplo, esPar(8) retorna true.

Ejercicio 3: Obtener el mayor de dos valores

fun mayor(a: Int, b: Int): Int {
    return if (a > b) a else b
}

Comparando los valores, la función devuelve el mayor. Para mayor(7, 3), el resultado será 7.

Ejercicio 4: Calcular el área de un círculo

fun areaCirculo(radio: Double): Double {
    return 3.14 * radio * radio
}

Se usa la expresión matemática del área. Por ejemplo, areaCirculo(2.0) da como resultado 12.56.

Ejercicio 5: Mostrar un saludo personalizado

fun saludar(nombre: String) {
    println("Hola, $nombre!")
}

La función imprime un mensaje utilizando el parámetro recibido. Llamar saludar("Andres") mostrará "Hola, Andres".
